# Pédale

Jeu de cyclisme sur route, vue 100 % de dessus. On incarne un seul coureur, de la première course à la fin de carrière.

- **Plan de travail : [`docs/chantiers.md`](docs/chantiers.md)** (chantiers, unités fonctionnelles, critères de validation)
- Vision fonctionnelle (référence, dans l'archive) : [`archives/v0.0.2-poc/docs/v0.0.1-design-fonctionnel.md`](archives/v0.0.2-poc/docs/v0.0.1-design-fonctionnel.md)
- Premier POC archivé : [`archives/`](archives/README.md)

Méthode : une application unique qui grandit chantier après chantier ; un chantier n'est démarré que lorsque le précédent est validé.
