# La chaîne complète sur un scénario de bout en bout (v0.0.3, brouillon)

Statut : **brouillon à corriger**. Complète `v0.0.3-comportement.md` (frontières entre étages). Ici on remplit chaque étage
**percevoir → interpréter → vouloir → agir** à partir d'un scénario, pour vérifier que la chaîne tient et que « rouler en groupe » en **émerge**.

## 1. Le scénario

- **Huit coureurs isolés**, pas d'équipes, pas de stratégie imposée. **Chacun veut gagner.** Rien d'autre.
- Personne n'a pour but de « rouler en groupe », de « faire un relais » ou de « s'organiser ». Ces comportements, s'ils apparaissent, sont des **conséquences** de choix individuels.
- Profils différents (les quatre archétypes du POC : rouleur, sprinteur, attaquant, opportuniste), mêmes lois physiques (vent, aspiration, fatigue).
- Départ lancé : les huit partent ensemble à la même allure. C'est une **condition initiale**, pas un comportement ; on pourra la changer (départ plus étalé) pour voir si le groupe se reforme.
- Pas de peloton, pas de poursuivants (décision v0.0.1).

### Ce que « gagner » implique (les trois leviers)
« Gagner » = franchir la ligne en premier. À l'échelle d'un coureur, cela se décompose en trois leviers, d'où viendront les intentions :
1. **Rester dans la course** : ne pas être lâché (sinon, il n'y a plus rien à jouer).
2. **Arriver avec des forces** : économiser tant que l'arrivée est loin.
3. **Battre les autres** : les user, les lâcher, ou les battre au sprint. Le bon moyen dépend du profil.

## 2. Inventaire par étage

Colonne « Code » : *existe* (déjà dans le POC), *à créer*, *à modifier*.

### 2.1 Percevoir (faits bruts, aucun jugement ; bruit et délai possibles)

| Fait | Détail | Code |
|---|---|---|
| Ma vitesse | exacte | existe |
| Mon effort ressenti | palier de puissance (Z1…Z7) | à créer |
| Ma fatigue ressentie | réserve d'endurance et explosivité, approximatives | existe (exact) → à bruiter |
| Mon abri ressenti | scalaire « vent dans la figure » | existe (exact) → à bruiter |
| Ma place | classement, dans la file ou à côté | existe |
| Les coureurs proches | position relative, vitesse relative (portée limitée) | à modifier (aujourd'hui : tous, exacts) |
| Les mouvements latéraux des autres | quelqu'un se décale | à créer |
| Les accélérations / ralentissements des autres | | à créer |
| Les indices visibles de l'état des autres | posture (cocottes, cintre, danseuse, écrasé) | existe côté rendu, pas dans la perception |
| La distance restante | compteur | existe |
| Le vent | de face et de côté ressentis | existe |
| Ma propre histoire | mon temps passé en tête | existe |

Ce que le coureur **ne perçoit pas** : la réserve exacte des autres, leur profil, leurs intentions. Il les déduit.

### 2.2 Interpréter (qualifier, construire des croyances, mémoire)

| Sur | Qualificatifs | Code |
|---|---|---|
| Moi | forme (frais / bien / limite / cuit), explosivité (pleine / entamée / vide), abrité / exposé, **budget** (ma réserve suffit-elle pour la distance restante ?) | existe, budget à créer |
| Ma situation | en tête / dans le groupe / décroché ; je viens de **hériter de la tête** | existe en partie |
| Les autres, état | **état apparent** (frais, marqué, à bout) déduit de la posture et du comportement | à créer |
| Les autres, disposition | **rouleur / suiveur / inconnu**, déduit de ce qu'ils ont fait (mémoire de qui a roulé) | à modifier (aujourd'hui `leadRecent` exact) |
| Les autres, danger | **sprinteur / attaquant supposé** | à modifier (aujourd'hui `archetype` et `pointe` exacts) |
| Les autres, intention | « il se décale : il va passer ou attaquer », « il accélère fort : attaque » | à créer |
| Le groupe | rythme (stable / monte / baisse), cohésion (serré / étiré) | à créer |
| La course | phase (loin / moyenne / proche / sprint), **fenêtre d'attaque** | existe en partie |
| Le risque | « je risque d'être lâché » | à créer |

### 2.3 Vouloir (choisir : intention, cible, palier, limites ; raisons nommées, vetos)

Chaque intention est une réponse à un levier de « gagner ». Les limites (palier max, fatigue max) sont recalculées à chaque évaluation.

| Intention | Levier | Pourquoi je la veux | Palier typique |
|---|---|---|---|
| **S'abriter** | 1 et 2 | Rester dans la course sans me fatiguer : je suis exposé, mon budget est serré, l'arrivée est loin. | Z2-Z4 (allure du groupe) |
| **Se placer** | 3 | Être proche de l'avant pour répondre aux attaques et préparer le sprint, sans me fatiguer. | Z3-Z5, ponctuel |
| **Participer** | 3 (et 1) | Imposer un rythme dur : user les rivaux dangereux pour moi, ou me débarrasser d'un sprinteur. | Z3-Z4, durable |
| **Attaquer** | 3 | Prendre de l'avance quand la fenêtre est bonne ou lancer le sprint. | Z6-Z7 |
| **Suivre** (un attaquant, une roue) | 1 et 3 | Ne pas laisser partir un rival dangereux. | Z5-Z6 |
| **Revenir** | 1 | Recoller à ceux qui sont devant. | Z4-Z5 |
| **Gérer** | 2 | Décroché : rythme personnel, jusqu'à ce que quelqu'un se rapproche. | Z2-Z3 |

À trancher : `attaquer`, `suivre`, `revenir`, `gerer` restent-ils des intentions à part, ou sont-ils des cas de « participer » / « s'abriter » avec d'autres limites ? Mon avis : `attaquer` et `suivre` restent (la fenêtre d'attaque et la réponse à une attaque sont de vraies décisions) ; `revenir` et `gerer` sont des variantes de s'abriter / participer quand on est décroché.

### 2.4 Agir (exécuter ; aucun arbitrage, aucune raison)

| Geste | Entrée | Compétence | Code |
|---|---|---|---|
| Tenir un palier | palier + limites | conversion en watts selon la physique et l'état | à modifier (aujourd'hui des coefficients dans `action.ts`) |
| Tenir une roue | cible, écart de confort | précision, délai de réaction | existe en partie |
| Chercher l'abri | abri ressenti | recherche locale, bruit | à créer |
| Remonter dans le groupe | place visée | couloir côté vent (coûteux) | à modifier |
| Reculer dans le groupe | place visée | lever le pied, rester dans le sillage | à créer |
| S'écarter, glisser | quitter la tête | | existe |
| Démarrer fort / sprinter | attaque, sprint | choix d'un couloir libre | existe |

Événements remontés vers Vouloir : `roue-perdue`, `place-atteinte`, `limite-atteinte`, `fin-burst`, `rejoint`.

## 3. Le scénario déroulé (cinq scènes)

Hypothèses de lecture à corriger. Coureurs : **R** (rouleur), **S** (sprinteur), **A** (attaquant). Aucun n'a pour but de « rouler en groupe ».

### Scène 1 : pourquoi on reste ensemble (départ)
- **Percevoir** : vitesse égale à celle des autres, vent dans la figure variable selon la place, distance restante grande.
- **Interpréter** : je suis dans le groupe, ceux qui sont derrière quelqu'un sont abrités.
- **Vouloir** : rester dans la course (levier 1) et économiser (levier 2) → s'abriter. Si je lâche le groupe, je roule seul, exposé, plus lentement.
- **Agir** : tenir la roue, chercher l'abri.
- **Ce qui émerge** : un groupe, **uniquement parce que l'aspiration rend avantageux de rester proche** (et que se faire lâcher fait perdre la course).

### Scène 2 : qui est devant, et pourquoi y reste-t-il ? (le point dur)
Un coureur est devant : il l'était au départ, ou il a hérité de la place.
- **Percevoir** : abri nul, vent de face, quelqu'un à 0,6 m derrière.
- **Interpréter** : je suis exposé, je suis en tête (une information comme une autre).
- **Vouloir** : si tout le monde cherche l'abri, ralentir lui fait perdre peu et fait passer les autres : **personne n'a de raison de rouler**. Il faut un motif : voir scène 3.
- **Agir** : maintenir le palier ou lever le pied, selon le vouloir.
- **Ce qui émerge** : selon les raisons, soit un coureur qui mène, soit une allure qui tombe (le « sur-place » classique en course).

### Scène 3 : le rythme (hétérogénéité des profils)
- **Percevoir** : l'allure du groupe, les postures des autres. Mémoire : S n'a jamais été en tête depuis 10 minutes.
- **Interpréter** : S = suiveur ; si la course est dure, il souffrira plus que moi (je suis rouleur).
- **Vouloir** (R) : **participer** à un rythme dur pour user S avant le sprint (levier 3). Les autres rouleurs qui y trouvent leur compte font de même.
- **Vouloir** (S) : s'abriter avec un palier max Z4 ; si R monte à Z5, `limite-atteinte` → il lâche ou répond.
- **Agir** : R tient Z4 devant ; les volontaires se placent devant les non-volontaires.
- **Ce qui émerge** : une **file de ceux qui veulent rouler** devant, des suiveurs derrière, des relais pour que les rouleurs restent frais. La **coopération vient de l'intérêt commun** (user les mêmes rivaux), pas d'une règle de relais.

### Scène 4 : une attaque
- **Percevoir** (A) : deux coureurs écrasés sur le vélo, 6 km à l'arrivée.
- **Interpréter** (A) : plusieurs coureurs marqués, fenêtre d'attaque ouverte.
- **Vouloir** (A) : attaquer, palier Z6, fatigue max moyenne. (Autres) : voir un coureur se décaler et accélérer → suivre ou laisser, selon leurs limites. Le coureur qui est cuit laisse ; S, encore frais, suit jusqu'à `entamer`.
- **Agir** : démarrage dans un couloir libre ; les autres réagissent avec leur délai.
- **Ce qui émerge** : tentatives qui réussissent ou échouent selon l'état des rivaux, sans règle « si 6 km alors attaque ».

### Scène 5 : le dernier kilomètre
- **Percevoir / Interpréter** : distance restante < 1 km, qui est frais, qui est devant.
- **Vouloir** : se placer (être bien placé pour le sprint) pour tous ; lancer le sprint à la distance que son explosivité permet.
- **Agir** : remonter par le côté, sprinter dans un couloir libre.
- **Ce qui émerge** : une bataille de placement avant le sprint, sans consigne « se mettre devant au dernier km ».

## 4. Ce qui doit émerger, et comment le vérifier

Le test d'un comportement émergent est de **retirer sa cause** et de regarder s'il disparaît :

| Comportement | Cause supposée | Test |
|---|---|---|
| Le groupe se forme et reste serré | aspiration + risque d'être lâché | aspiration à zéro : le groupe doit se disperser |
| Des coureurs roulent devant | profils différents (user les rivaux) | huit profils identiques : pas de rouleur désigné, allure qui tombe ou rotation égale |
| Des « rouleurs » devant, des « suiveurs » derrière | intérêts différents | rouleurs seuls : plus de suiveurs |
| Des attaques | fenêtre d'attaque (rivaux marqués, distance) | huit coureurs frais et aucune fenêtre : peu d'attaques |
| Une bataille de placement à la fin | le sprint se joue sur la position | pas de vouloir `se placer` : le placement est subi |

## 5. Écarts du code actuel avec ce scénario

- **Omniscience** : `AutreCoureur` expose `archetype`, `pointe`, `leadRecent` exacts. Un coureur isolé ne connaît pas le profil des autres (sauf réputation, voir questions).
- **Comportements sociaux déjà écrits** : les raisons `reciprocite`, `dejaPris`, `quelquunPasse`, `rang` et le trait `generosite` présupposent qu'on roule en groupe selon des règles. À justifier par l'intérêt individuel, ou à garder comme trait explicite.
- **Intensités et phases dans Agir** (voir `v0.0.3-comportement.md` §3).

## 6. Questions pour le propriétaire

1. **Qu'est-ce qui fait rouler ?** Sans menace extérieure (pas de poursuivants), si tous veulent gagner, rouler devant n'a d'intérêt que pour user les autres (scène 3) ; avec huit profils proches, l'allure peut tomber, comme dans une vraie course tactique. Options :
   - a. Accepter cela (aucune autre incitation) et voir ce qui se passe en simulation. **Recommandé pour commencer.**
   - b. Ajouter une information de menace abstraite (« écart avec les poursuivants »), sans les simuler.
   - c. Garder `generosite` comme trait de culture de course (fair-play), à la place de b.
2. **Réciprocité et générosité** : les garder comme traits explicites, ou les retirer au profit de l'intérêt individuel (et d'une réputation perçue par les autres) ?
3. **Départ** : en file serrée comme aujourd'hui, ou groupé en largeur pour voir la file se former ?
4. **Connaissance des autres** : un coureur connaît-il leur profil par réputation (comme des pros), avec du bruit, ou les découvre-t-il seulement à leur comportement ?
5. **Intentions** : confirmer la proposition de §2.3 (garder `attaquer` et `suivre`, intégrer `revenir` et `gerer`).
