# Aspiration (v0.0.2)

## Où elle est dans la simulation
L'aspiration est **dans la physique** : c'est une réduction de la traînée aérodynamique d'un coureur placé derrière un autre (`packages/sim/src/physics.ts`, `ASPIRATION`, `aspirationValeur`, `aspiration`).

- Pour **un** coureur devant : `réduction = 0,45 · e^(−écart / 3 m) · (1 − décalage / 0,9 m)`, où *écart* est la distance entre sa roue arrière et ma roue avant, et *décalage* mon écart latéral à son sillage. Valeurs : 0,5 m ≈ 38 %, 1 m ≈ 32 %, 3 m ≈ 16 %, 6 m ≈ 6 %, au-delà de 14 m : 0.
- Avec deux coureurs devant : le premier compte plein, le second pour 25 % ; plafond 48 %.
- **Vent de côté** : le sillage dérive latéralement (`écart · tanβ`), d'où l'éventail.
- Elle réduit la traînée donc la **puissance nécessaire** pour une vitesse donnée (à 35 km/h, ~35 % d'économie à 1 m).

## Ce qui pousse à prendre la roue
Ce n'est **pas** une décision (*Vouloir*), c'est un réflexe d'*Agir*, appliqué à toutes les intentions où l'on suit quelqu'un :
- la roue visée est celle du coureur de la file qui m'abrite ;
- écart visé : **0,5 m** ; vitesse visée = vitesse de la roue + 1,1 × (écart − 0,5) ;
- **valeur de l'abri** : plus l'écart est grand, plus on est prêt à forcer pour le refermer : jusqu'à +22 % de puissance soutenable (via l'explosivité) quand l'écart dépasse ~5 m ;
- trop près (< 0,5 m) : on freine (jusqu'à 2,5 m/s²).

L'incitation est donc implicite : l'aspiration fait économiser de la puissance, et le suiveur vise l'écart qui l'optimise. Elle n'apparaît pas comme une « raison » dans la trace.

## Visualisation
- **Curseur « Aspiration »** (touche `A` pour basculer) : dessine, derrière chaque coureur, le sillage dans lequel un suiveur trouverait de l'abri ; plus c'est marqué, plus l'aspiration est forte ; il dérive avec le vent de côté.
- **« abri x % »** par coureur dans la liste (réduction de traînée actuelle).

## Limites / pistes
- Le coureur de derrière d'un relais peut encore rester à 3-6 m dans ~10 % des cas (plafond de puissance atteint).
- Pas de choix « tactique » de se placer en second plutôt que de prendre la roue immédiate ; pas de bordure formée à plusieurs files.
- Le curseur ne règle que l'affichage ; si on veut aussi faire varier la force de l'aspiration, c'est `ASPIRATION.base` / `longueur` (à décider).
